# LinkedIn Social Network Analysis

This repository contains a Social Network Analysis (SNA) project using LinkedIn connection data to study influence, connectivity, and community structure.

## Dataset

This project uses LinkedIn connection data.

For privacy reasons, the original `Connections.csv` file obtained from LinkedIn is **not included** in this repository.

To use your own data:
1. Download `Connections.csv` from LinkedIn
2. Place it inside the `data/` folder
3. Update the file path in the notebook
